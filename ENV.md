# ENV — admin (frontend)

Скопируй `env.example` → `.env`. Ниже — что значит каждый ключ.

- **VITE_API_BASE_URL**: base URL backend API для админки (Vite build-time).
- **VITE_RECOGNITION_STREAM_BASE_PORT**: базовый порт распознавания для MJPEG стримов (используется для формирования URL стрима).
