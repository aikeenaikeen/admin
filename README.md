# Admin Frontend

Административная панель для управления системой учета посещаемости.

## 🎯 Назначение

Admin Frontend предоставляет веб-интерфейс для:
- Управления компаниями (для суперадмина)
- Управления пользователями
- Управления камерами
- Управления сотрудниками
- Просмотра событий распознавания
- Статистики и аналитики посещаемости
- Live просмотра камер

## 🛠️ Технологический стек

- **Vue.js 3** - UI фреймворк
- **TypeScript** - Типизация
- **Vite** - Build tool
- **Vue Router** - Роутинг
- **Pinia** - State management
- **Axios** - HTTP клиент

## 🚀 Быстрый старт

1. Создайте `.env` на основе [env.example](./env.example).
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
4. Для production-сборки используйте:
   ```bash
   npm run build
   npm run preview
   ```

Если нужен полный локальный запуск через nginx и docker compose, используйте [infra/README.md](../infra/README.md).

## 🔐 Роли пользователей

### Суперадмин
- ✅ Управление всеми компаниями
- ✅ Создание/редактирование компаний
- ✅ Управление пользователями всех компаний
- ✅ Просмотр статистики по всем компаниям

### Админ компании
- ✅ Управление камерами своей компании
- ✅ Управление сотрудниками
- ✅ Управление пользователями компании
- ✅ Просмотр событий и статистики
- ❌ Не видит другие компании

### Обычный пользователь
- ✅ Просмотр событий
- ✅ Просмотр статистики (read-only)
- ❌ Нет управления

## 📱 Основные страницы

### Dashboard
- Общая статистика
- Последние события
- Активные камеры

### Камеры
- Список IP-камер
- Добавление/редактирование камер
- Тест подключения
- Включение/выключение распознавания

### Сотрудники
- База сотрудников
- Загрузка фотографий
- Статус (активен/неактивен)

### События
- История распознаваний
- Фильтры по дате, камере, сотруднику
- Экспорт данных

### Статистика
- Графики посещаемости
- Отчеты по сотрудникам
- Аналитика по времени

### Live
- Просмотр камер в реальном времени
- Мультивью (несколько камер)

## 🎨 UI/UX

- Адаптивный дизайн (desktop-first)
- Темная/светлая тема (опционально)
- Интуитивная навигация
- Real-time обновления (WebSocket)

## 🔗 API Integration

Все запросы идут через Backend API:
```typescript
// api/client.ts
const API_BASE_URL = import.meta.env.VITE_API_BASE_URL;

axios.get(`${API_BASE_URL}/cameras`)
```
